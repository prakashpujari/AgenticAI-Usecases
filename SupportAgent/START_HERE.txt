🚨 TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════════════

Problem:  Services not starting
Solution: docker-compose down && docker-compose up -d

Problem:  Tests failing
Solution: docker-compose logs backend

Problem:  Port already in use
Solution: Change API_PORT in .env

Problem:  Database error
Solution: docker-compose down -v && ./start_local.sh

Problem:  Complete reset needed
Solution: docker-compose down -v --remove-orphans && ./start_local.sh
